# 📸 Instagram Story Downloader

Download Instagram Stories, Reels, Photos, Videos, Posts and Highlights in one place.

- Instagram Story Downloader
- Instagram Reels Downloader

## 📱 How to Use

1. Open the website.
2. Copy the Instagram post, reel or story link.
3. Paste the link into the input box.
4. Click the Download button.
5. Download the available media.

## 🚀 Deployment

This project can be deployed using Netlify.

1. Open Netlify.
2. Connect your GitHub repository.
3. Select your project.
4. Click Deploy.
